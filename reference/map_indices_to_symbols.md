# Map integer indices to symbol values with type coercion

Map integer indices to symbol values with type coercion

## Usage

``` r
map_indices_to_symbols(indices, syms, field)
```

## Arguments

- indices:

  Integer vector of 1-based symbol indices (NA = null).

- syms:

  Symbol vector for this field.

- field:

  Field metadata list.

## Value

A typed R vector.
